## 外形与内部尺寸

坐标系：PCB 左下角为 `(0, 0)`，Z = 0 为**内腔底面**（底板内侧表面）。
外形以 PCB 为中心，STL 包围盒为 `X -4.40 … 100.92`、`Y -4.40 … 80.60`、`Z -2.40 … 24.40`。

| 项目 | 数值 |
| --- | --- |
| PCB 尺寸 | 96.52 × 76.20 × 1.60 mm |
| 外壳外形 | 105.32 × 85.00 × 26.80 mm |
| 外形圆角 | R5.0 |
| 壁厚 / 底板厚 / 顶盖厚 | 2.40 / 2.40 / 2.40 mm |
| 板边到内壁间隙 | 2.00 mm（内腔圆角 R3.0） |
| 内腔 | X −2.00 … 98.52，Y −2.00 … 78.20，深 22.00 mm |
| PCB 安装面高度 | Z = 5.00 mm（板背面焊点离底板 5.00 mm） |
| PCB 顶面 | Z = 6.60 mm |
| PCB 下表面 → 顶盖下表面 | 17.00 mm（PCB 顶面上方 15.40 mm） |
| 顶盖下表面 / 上表面 | Z = 22.00 / 24.40 mm |

实测元件高度：ESP32 堆叠约 13.1 mm，OLED 约 12.5 mm，ZE08 顶部到 PCB 下表面 13 mm
（Z = 18.0），充电口顶部到 PCB 下表面 17 mm（Z = 22.0，正好顶到顶盖），
EN/BOOT 轻触开关顶部到 PCB 下表面 16 mm（Z = 21.0，距顶盖 1 mm）。

## 螺丝位置（共 8 个 M2 自攻）

### PCB 固定：6 个

```
(12.70, 5.08)   (48.26, 5.08)   (83.82, 5.08)
(12.70, 71.12)  (48.26, 71.12)  (83.82, 71.12)
```

柱体 Ø5.00 × 高 5.00 mm，导孔 **Ø1.65 × 深 7.00**（盲孔，不穿透底板）。

### 上盖固定：2 个（接缝处）

| 编号 | 位置 | 靠哪面墙 |
| --- | --- | --- |
| 1 | (3.00, 38.10) | 左壁 |
| 2 | (93.52, 38.10) | 右壁 |

- 底壳：**Ø5.0 螺丝柱，柱顶与接缝齐平（Z = 22.00）**，导孔 **Ø1.4 × 深 4.0**
- 上盖：**Ø2.2 过孔**，贯穿 2.4 mm 顶板
- 螺丝建议 M2 × 6（自攻）

前后两面**不放螺丝**：那两个柱子落在 PCB 的前后边上，板子从上方下不去。左右两个柱子位于
板子左右边的中段，装板时把板子略微倾斜、左（右）边先下去、让开柱子再放平即可。
上盖靠 2 颗螺丝 + 摩擦唇边固定，强度足够。

**为什么柱子是"吊"在接缝上的**：接缝以下 22 mm 内腔里没有可站立的实体，柱子只能从
内壁挑出来。为了免支撑打印，每个柱子做成三段：

1. **Ø5 圆柱**（Z 16.5 … 22.0）——真正吃螺丝的部分；
2. **45° 锥体**（Ø5 收到尖，Z 16.5 → 14.0）——柱底没有平悬空面，逐层内收，不需要支撑；
3. **45° 斜肋**（从柱身斜下来贴到内壁，Z 10.9 … 19.0）——把柱子连到墙上，斜面同样自支撑。

斜肋顶只到 Z = 19.0，比唇边底面（19.40）低 0.4 mm，合盖时唇边不会顶在肋上。

> 导孔直径：你说 1 mm，这里给的是 **1.4 mm**。M2 自攻在 PLA 里用 1.0 mm 导孔会把
> Ø5 的柱子撑裂，1.4 mm 已经很紧。想要更紧就改 `LID_PILOT_D`，但别低于 1.2。

## 按钮（2 个）

位置对应 ESP32 开发板充电口两侧的 EN / BOOT 轻触开关：

| 项目 | 数值 |
| --- | --- |
| 位置 | (4.50, 46.48) 和 (4.50, 62.48)（间距 16.0） |
| 顶盖开孔 | Ø4.50 通孔 |
| 按钮柱杆 | Ø4.00 × 长 3.80 |
| 按钮柱底盘 | Ø6.60 × 厚 0.80 |
| 装配后 | 底盘下表面 Z = 21.2，开关顶面 21.0，留 0.2 mm 空行程 |
| 顶盖外露出 | 0.60 mm |

按钮柱从顶盖内侧穿进去，**底盘 Ø6.6 大于 Ø4.5 的孔，所以卡在壳里掉不出来**；
合盖后底盘正好落在轻触开关上方，按 0.6 mm 就能触发。打印时底盘朝下平放，无需支撑。

## 传感器按压凸台

顶盖内侧在每个模块排针正上方做一个凸台，合盖后把模块压住、防止从插座里松脱：

| 模块 | 位置 | 凸台尺寸 | 凸出高度 | 底面 Z |
| --- | --- | --- | --- | --- |
| ZE08（橙色） | (17.145, 10.541) | 12 × 7，R2 | **6.50 mm** | 15.50 |
| SHT4x | (48.260, 10.541) | 12 × 7，R2 | **1.50 mm** | 20.50 |
| SGP40 | (78.486, 10.541) | 12 × 7，R2 | **1.50 mm** | 20.50 |
| OLED | (72.009, 66.400) | 12 × 7，R2 | **1.50 mm** | 20.50 |

凸台中心对准 PCB 上的 4/5 芯排针，宽度 12 mm 同时压住排针和模块板边；
底部带 R2 圆角，蹭到模块时不会刮板。改高度只需改 `PRESS_PADS` 里每行最后一个数。

OLED 凸台往后偏了 0.5 mm，与 OLED 窗口之间留 1.1 mm 料厚，避免窗口边缘太薄。

### 为什么充电口开成"通到接缝"的缺口

充电口顶部离 PCB 下表面 17 mm，顶盖下表面也正好 17 mm。任何低于该高度的开孔都会挡住插头，
所以左壁开口做成从 `z = 17.5` 一直开到接缝的缺口；顶盖唇边在对应位置留 18 mm 让位缺口
（见 `preview_lid_bottom.png` 左侧那段断开）。

**顶盖边缘还要再切一刀**：插头的注塑外壳比接口本身高约 1.5–2 mm，如果顶盖边缘压到接缝上，
插头还是插不进去。所以顶盖左边缘在充电口上方再让出 **18 mm 宽、4.0 mm 深、贯穿顶板**的缺口，
插头外壳可以一直抬到 Z = 24.4 以上。代价是从正面能看到这一小段开口（见 `preview_assembly.png`
左上角），属于这类接口贴近接缝时不可避免的取舍；嫌大可以把 `PORT_RELIEF_D` 从 4.00 调小。

### 开孔是怎么测出来的

照片正俯视，用 6 个安装孔标定（X 向 11.74 px/mm、Y 向 11.12 px/mm，照片有约 5% 纵向拉伸，
两轴分别标定），再以各模块自己的排针中心为局部基准量取，误差约 ±1 mm：

| 模块 | 实测（换算后） | 说明 |
| --- | --- | --- |
| OLED 玻璃 | 中心 (72.2, 54.8)，26.7 × 14.7 | 0.96" 模块，有效显示区 21.7 × 10.9 |
| ZE08 感应元件 | 中心 (17.2, 21.5)，Ø10 | 橙色圆柱，比排针高约 11 mm |
| SHT4x 感应口 | 中心 (47.0, 17.3)，Ø3.8 | 白色圆孔偏模块左上 |
| SGP40 感应口 | 中心 (76.4, 17.0)，Ø3.6 | 白色圆孔偏模块左侧 |

网孔只覆盖感应元件，孔 Ø1.6、间距 2.4（筋宽 0.8 mm），开孔率约 20–24%。

## 顶盖配合

| 参数 | 数值 |
| --- | --- |
| 唇边厚度 / 高度 | 1.60 / 2.60 mm |
| 单边间隙 | 0.15 mm |
| 摩擦凸筋 | 周圈外伸 0.30 mm（Z 20.10 … 21.05），实际过盈 0.15 mm |
| 减压槽 | 4 条，四边中部，宽 1.4 mm |
| 充电口让位 | 左壁 18 mm 唇边缺口 |

顶盖由 2 颗 M2 螺丝 + 摩擦唇边共同固定。若过紧，`RIB_OUT` 从 0.30 调到 0.20；
若晃动，`LIP_CLEAR` 从 0.15 调到 0.10。

## 装配步骤

1. PCB 放在 6 个支撑柱上，四周留约 2 mm 均匀间隙，拧入 6 颗 M2 自攻（M2 × 6）。
2. 插好传感器、OLED、ESP32（充电口朝左侧缺口）。
3. 把 2 个按钮柱从**顶盖内侧**穿进 Ø4.5 孔，底盘朝内。
4. 合上顶盖，先压充电口一侧，再压其余三边。
5. 从顶盖穿 2 颗 M2 自攻拧入接缝处的柱子。
6. 拆卸：拧掉 2 颗螺丝，用一字螺丝刀插入前壁撬盖槽向上撬。

## 打印建议

- **底板**：底面朝下，开口朝上，无需支撑。2 个螺丝柱的锥体和斜肋都是 45° 自支撑面。
- **顶盖**：**外表面朝下**（`preview_top.png` 那一面贴平台），唇边朝上，无需支撑。
- **按钮柱**：底盘朝下平放，杆朝上，无需支撑，一次打 2 个。
- 参数：层高 0.16–0.20 mm，外壁 3 圈，顶/底实心层 4 层，填充 15–25%。
- 材料：PLA 或 PETG；气敏传感器怕潮，长期户外建议 PETG。
- 实体体积（100% 填充上限）：底板 41.8 cm³、顶盖 21.7 cm³、按钮 2 × 0.1 cm³。

## 修改尺寸与重新生成

关键参数都在 `generate_enclosure.py` 开头：

```python
PCB_LIFT      = 5.00    # PCB 下表面到内腔底面
PCB_TO_LID    = 17.00   # PCB 下表面到顶盖下表面
SCREW_POS     = [...]   # 2 个上盖螺丝位置
LID_PILOT_D   = 1.40    # 上盖柱导孔
BUTTONS       = [...]   # 2 个按钮位置
PRESS_PADS    = [...]   # 4 个按压凸台（位置 + 凸出高度）
```

重新生成：

```powershell
& "D:\APP\Blender Foundation\Blender 5.2\blender.exe" -b --python "3Dmodel\generate_enclosure.py"
```

脚本会覆盖 3 个 STL 和 `.blend`，并打印顶点数、面数、非流形边数量（应为 0）。

重新渲染预览：

```powershell
& "D:\APP\Blender Foundation\Blender 5.2\blender.exe" -b "3Dmodel\ESP32AirCheck_enclosure.blend" --python "3Dmodel\render_preview.py"
```
